# mK What's New

HTML do e-mail mensal de novidades de produto para clientes.

Uma pasta por mês, no formato `AAAA-MM`. Dentro dela, o `index.html` do e-mail e as imagens que ele usa.

```
2026-10/
  index.html
  imagens/
```

O envio é feito pelo time de CS com a skill `woow-news`, que lê o HTML deste repositório. Antes de subir, confira no navegador se as imagens carregam e se todos os links abrem a página certa.
