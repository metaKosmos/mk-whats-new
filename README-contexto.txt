MetaKosmos — Newsletter mK What’s New

Projeto: newsletter de novidades das soluções da MetaKosmos, em HTML para e-mail com tabelas, CSS inline e ajustes responsivos. Este pacote contém SOMENTE a newsletter, sem a Landing Page/Home.

Estrutura:
- 2026-10/index.html: única versão final do e-mail de outubro de 2026, com assinatura da Gabi e links de WhatsApp, Instagram e LinkedIn.
- 2026-10/imagens/: os 11 arquivos de imagens, logos e GIFs usados pela newsletter. O HTML mantém os src HTTPS absolutos do CMS, adequados para envio de e-mail; os arquivos locais são cópias para preservação e manutenção.
- README.md: instruções existentes do repositório, mantidas intactas.

Versionamento: o projeto será mantido via Git no repositório da Organização metaKosmos no GitHub: https://github.com/metaKosmos/mk-whats-new. Seguir a organização mensal AAAA-MM já definida pelo repositório.

Prévia/envio: abra 2026-10/index.html no navegador com acesso à internet. Para envio, importe esse HTML na ferramenta de e-mail. As imagens e fontes externas dependem dos serviços hospedados.

Pendência existente: os links Privacidade e Descadastrar ainda usam example.com e precisam dos destinos finais antes do disparo.
